# Публикация АПО.ТИМИМО в GitHub

Проект: **АПО.ТИМИМО**, разработка команды **КАИРО**, разработчик **Иващенко Сергей Сергеевич**.

## Размещение в отдельном репозитории

1. Откройте https://github.com/new, выберите имя `APO-TIMIMO` и нужную видимость (Public или Private). Не создавайте дополнительные README, .gitignore или LICENSE — в проекте уже есть README и .gitignore.
2. Скачайте `APO_TIMIMO_GitHub_Ready_v0.1.1.zip`, распакуйте и загрузите **содержимое** каталога в корень репозитория, включая скрытую папку `.github`.
3. В `Actions` выберите **Build APO.TIMIMO for Windows macOS and Linux** → **Run workflow**, чтобы запустить проверку и сборку на четырёх системах.
4. После успешной сборки скачивайте четыре результата на странице запуска в секции **Artifacts**.

## Автоматические релизы GitHub

После проверки сборок создайте в GitHub версионный тег `v0.1.1` на основной ветке (через интерфейс GitHub или `git tag v0.1.1 && git push origin v0.1.1`). Появление тега запустит сборку и публикацию четырёх пакетов в разделе **Releases**. Не создавайте тег, пока предыдущий запуск workflow не завершился успешно.

## Важно

- Поддержка Windows и macOS требует реального запуска GitHub Actions на соответствующих системах; готовность не подтверждается только исходным кодом.
- Пакеты не имеют сертификата подписи разработчика; Windows SmartScreen и macOS Gatekeeper могут показывать предупреждения.
- Программа работает локально, но история сканирования содержит сведения о ПО на компьютере. Не публикуйте личные отчёты пользователя в репозитории.
- Исходный код опубликован **без открытой лицензии**: если планируется разрешить другим использование, изменение или распространение программы, отдельно выберите и добавьте LICENSE.
