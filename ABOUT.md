# Сведения о программе «АПО.ТИМИМО»

**Название:** АПО.ТИМИМО  
**Назначение:** аудит установленного программного обеспечения на одном компьютере  
**Версия:** 0.1.1  
**Разработка:** команда КАИРО  
**Разработчик:** Иващенко Сергей Сергеевич

АПО.ТИМИМО — настольная программа для локальной инвентаризации установленного программного обеспечения. Приложение собирает доступные сведения о названиях и версиях программ, их издателях, источниках и путях установки, позволяет выполнять поиск, сохранять результаты проверок и формировать отчёты.

Программа поддерживает Windows, macOS и Linux; полнота сведений зависит от операционной системы, её системных источников и прав пользователя. При обычном сканировании программа не изменяет установленное ПО и не передаёт сведения на сервер.

**Логотип:** оригинальный графический знак, предоставленный заказчиком; представлен в ресурсах приложения (`software_audit/assets/logo-original.png`).

**Примечание:** текущая версия является MVP для инвентаризации ПО. Автоматическая проверка CVE, цифровых подписей и актуальности обновлений пока не реализована.
