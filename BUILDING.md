# АПО.ТИМИМО: сборка приложений для Windows, macOS и Linux

**Проект:** АПО.ТИМИМО, версия 0.1.1. **Разработка:** команда КАИРО. **Разработчик:** Иващенко Сергей Сергеевич.

## Что находится в проекте

- `software_audit/`: локальный сканер программ, интерфейс Tkinter, экспорт, логотипы.
- `launcher.py`: основной вход для запакованного приложения; `--self-test` проверяет наличие ресурсов и реальный PDF-экспорт без графического окружения.
- `scripts/build_release.py`: сборка с PyInstaller для **текущей** операционной системы.
- `.github/workflows/build-native.yml`: параллельная сборка в GitHub Actions на Windows 2022 x64, macOS 15 Apple Silicon, macOS 15 Intel и Ubuntu 22.04 x64.
- `scripts/package_linux_embedded.py`: запасная локальная версия для Debian 13 x64 с включённым Python 3.13 (не универсальная сборка Linux).

## Получение настоящих исполняемых файлов для всех ОС

1. Создайте новый репозиторий GitHub и загрузите **содержимое** исходного ZIP, включая скрытую папку `.github`.
2. Убедитесь, что файлы находятся в основной ветке (`main` или другая default branch).
3. Откройте на GitHub **Actions → Build APO.TIMIMO for Windows macOS and Linux → Run workflow**.
4. После **успешного завершения** четырёх заданий откройте страницу запуска и скачайте файлы из секции **Artifacts**.

Пакеты, которые должен создать процесс:

| Платформа | Файл внутри загруженного артефакта | Запуск |
|---|---|---|
| Windows x64 | `APO_TIMIMO_v0.1.1_Windows_x64.zip` | Извлечь и открыть `APO_TIMIMO.exe` |
| macOS Apple Silicon | `APO_TIMIMO_v0.1.1_macOS_arm64.zip` | Извлечь и открыть `APO_TIMIMO.app` |
| macOS Intel | `APO_TIMIMO_v0.1.1_macOS_x64.zip` | Извлечь и открыть `APO_TIMIMO.app` |
| Linux x64 (Ubuntu 22.04) | `APO_TIMIMO_v0.1.1_Linux_x64.tar.gz` | Извлечь и выполнить `./Start_APO_TIMIMO.sh` |

Из-за устройства PyInstaller **нативный исполняемый файл собирается на своей ОС**. Workflow позволяет не устанавливать все три ОС локально.

> Важно: эту автоматическую сборку ещё необходимо запустить на GitHub. Наличие YAML-файла не означает, что Windows/macOS-исполняемые файлы уже созданы или проверены. Пакеты без цифровой подписи; macOS Gatekeeper и Windows SmartScreen могут показывать предупреждения. Не отключайте антивирус или общую защиту системы: для распространения подписывайте сборки сертификатами.

## Самостоятельная нативная сборка на текущей ОС

Установите Python 3.12 с Tkinter, затем из корня проекта:

```bash
python -m pip install "pyinstaller>=6.12,<7" "reportlab>=4,<5" "pillow>=10,<13"
python -m unittest discover -s tests -v
python scripts/build_release.py
```

На Windows, если `python` недоступен, замените его на `py -3`. Результаты находятся в `releases/`. Программа не требует Python на конечном компьютере после успешной PyInstaller-сборки, но требуются системные компоненты GUI и совместимая версия ОС.

## Проверенные сейчас результаты

В среде Debian 13 x86_64 протестирован специальный пакет `APO_TIMIMO_v0.1.1_Linux_Debian13_x86_64.tar.gz` со встроенным Python. Проверка `./APO_TIMIMO --self-test` завершилась успешно, PDF-экспорт создан; окно запустилось под Xvfb. **Этот пакет нельзя считать универсальным для других Linux**: нужна glibc ≥2.41 и работающая графическая среда X11. Для более широкой совместимости используйте сборку Linux из GitHub Actions (Ubuntu 22.04).

## Режим из исходного кода (Python требуется)

Если нет готового нативного пакета, `APO_TIMIMO_Windows_SOURCE_v0.1.1.zip` запускается через `START_WINDOWS.cmd`, а `APO_TIMIMO_macOS_SOURCE_v0.1.1.zip` — через `START_MACOS.command`. Оба пакета **требуют установленный Python** и не являются самостоятельными `.exe`/`.app`.

## Безопасность и приватность

Сканирование локальное; программа считывает реестр или базы пакетных менеджеров, ничего не удаляет и не отправляет на внешние серверы. История сохраняется в домашнем каталоге пользователя. Проверка CVE и цифровых подписей пока не реализована.
